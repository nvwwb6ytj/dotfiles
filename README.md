# dotfiles

Personal configuration files for macOS and Linux.

## Contents

- `.zshrc` — shell aliases, prompt, and history settings
- `.gitconfig` — global git config with aliases
- `.vimrc` — Vim settings and plugins
- `.tmux.conf` — tmux keybindings and status bar

## Setup

Clone and symlink:

```bash
./install.sh
```

Or manually copy files to your home directory.

## Notes

- Works with zsh and bash
- Tested on macOS Sonoma and Ubuntu 24.04
